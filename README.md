# C Mono Modules

Focused C exercises organized by algorithmic family.

## Goal

Build strong fundamentals in C problem solving through small, isolated modules.

## Constraints

- C language
- `stdio.h`
- no dynamic memory unless explicitly stated
- no external libraries
- no `string.h` in early exercises
- static arrays and matrices
- clear input/output behavior

## Structure

Each exercise contains:

- `README.md` — problem statement and constraints
- `main.c` — implementation
- `tests.txt` — manual test cases
- `postmortem.md` — mistakes, reasoning and transferable pattern

## Families

- linear scan
- two pointers
- parsing and tokenization
- strings
- matrices
- records
- recursion
- data structures
- greedy
- dynamic programming
- graphs
